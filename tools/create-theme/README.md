# @picloom/create-theme

Create a standalone Picloom Vue 3 theme with Bun 1.4.3+.

```sh
bun create @picloom/theme@0.1.1 ./my-theme
cd my-theme
bun install
bun run dev
bun run typecheck
bun run build
```

The target directory must not exist and its parent must exist. Follow the generated README to edit and install the ZIP. The dev server provides a simulated preview. Type checking and building are separate commands.

[Theme tutorial](https://llleixx.github.io/picloom/development/theme-tooling.html)
